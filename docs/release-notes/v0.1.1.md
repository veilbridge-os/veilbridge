Installable package for OpenWrt.

- `.ipk` package with a procd service that starts on boot and an owner-only
  `/etc/veilbridge`
- One-command installer that picks the CPU and verifies the checksum

> **OpenWrt 25.12 and later:** this release has no `.apk` package, so it cannot
> be installed there. Use [v0.1.2](https://github.com/veilbridge-os/veilbridge/releases/tag/v0.1.2)
> or newer.

Written retroactively on 2026-09-25; see [`CHANGELOG.md`](https://github.com/veilbridge-os/veilbridge/blob/main/CHANGELOG.md).
